# M6 Chapter 5: Property, Plant and Equipment — Phase 3 Answers

### Q1 — Answer: C (HK$509,000)

**Model Answer (EN):**
Workings — capitalise only the purchase price and directly attributable costs (HKAS 16.16–16.17):
- Purchase price: HK$500,000 − trade discount HK$25,000 = HK$475,000
- Import duty (non-refundable tax): HK$8,000
- Delivery and installation: HK$20,000
- Testing costs: HK$6,000
- **Cost of machine = HK$475,000 + 8,000 + 20,000 + 6,000 = HK$509,000**

Excluded: refundable VAT HK$12,000 (recoverable, not a cost); staff training HK$9,000 and opening ceremony HK$4,000 (HKAS 16.19–20: costs of conducting business with a new class of operation and opening a new facility are expensed).

**解題思路（繁中）:**
- 關鍵係逐項問「係咪令部機 ready for intended use 所必需」。
- Option A（HK$521,000）錯誤加咗可退還 VAT — VAT 係 refundable tax，收回得返，唔係資產成本。
- Option B（HK$534,000）= 正確數 509,000 + VAT 12,000 + training 9,000 + ceremony 4,000，全部錯誤資本化。
- Option D（HK$530,000）= 509,000 + VAT 12,000 + training 9,000，同樣錯。
- Trade discount 一定要扣（HKAS 16.16(a)）；import duty 係 non-refundable → 資本化；testing 同 delivery/installation 係典型 directly attributable costs。

**Rule Check:** HKAS 16 para. 15–17; HKAS 16 para. 19–20 (excluded costs)

**Common Trap（繁中）:** 見到稅項就諗清楚：VAT refundable → expense/ receivable；stamp duty、import duty non-refundable → capitalise。Training 同 opening ceremony 無論點包裝都係費用。

### Q2 — Answer: B

**Model Answer (EN):**
Under HKAS 16.55, depreciation of an asset **begins when it is available for use**, i.e. when it is in the location and condition necessary for it to be capable of operating in the manner intended by management — here, 1 October 20X4. Depreciation does not cease while an asset is idle; an idle but ready-for-use asset continues to be depreciated (under a usage method the charge may be zero, but Otter's idleness arises from low seasonal demand, not from a usage-method outcome).

**解題思路（繁中）:**
- 考點係「ready for use 即刻開始折舊」，唔係「開始用」先折。10月1日已達到 location and condition necessary → 當日開始折。
- Option A 錯：延到實際使用日（1月1日）先折，違反 16.55。
- Option C 錯：idle 唔等於停止折舊；折舊只喺 earlier of held for sale（HKFRS 5）或 derecognition 時先停。
- Option D 錯：無「閒置一個月自動停止折舊」呢回事——徹底虛構嘅規則。
- 考試伏位：題目畀兩個日期（ready 日 vs 使用日）就係引你揀遲嗰個。

**Rule Check:** HKAS 16 para. 55 (commencement and cessation of depreciation)

**Common Trap（繁中）:** 同學常將「開始折舊」同「開始使用」混淆。記住：depreciation reflects consumption of service potential, and an idle asset still deteriorates。

### Q3 — Answer: A (HK$52,500)

**Model Answer (EN):**
Workings:
- Depreciable amount = HK$480,000 − HK$60,000 = HK$420,000
- Annual depreciation (straight-line) = HK$420,000 ÷ 6 = HK$70,000
- Depreciation commences 1 April 20X4 (asset acquired and ready for use); 9 months to 31 December 20X4
- Depreciation expense 20X4 = HK$70,000 × 9/12 = **HK$52,500**

**解題思路（繁中）:**
- 兩個計算步驟：先扣 residual value 計 depreciable amount，再按月 pro-rate。
- Option B（HK$70,000）：計咗全年，忽略咗 4月1日先買入（題目明講 monthly depreciation）。
- Option C（HK$60,000）：忽略 residual value（480,000 ÷ 6 = 80,000 × 9/12 = 60,000）。
- Option D（HK$80,000）：既忽略 residual value 又計全年 — 雙重錯誤。
- Straight-line 一定要扣 residual value；只有 diminishing balance 先唔扣（residual value 只作下限）。

**Rule Check:** HKAS 16 para. 50 (depreciable amount); HKAS 16 para. 55 (depreciation commences when ready for use)

**Common Trap（繁中）:** Mid-year acquisition + monthly depreciation 係 M6 官方常見出法。唔記得 pro-rate 或唔扣 residual value 都會中伏。

### Q4 — Answer: D

**Model Answer (EN):**
Under the net method (HKAS 16.35(b)), accumulated depreciation is first eliminated against the gross carrying amount, then the carrying amount is adjusted to fair value:
| Account | Dr HK$ | Cr HK$ |
|---|---|---|
| Accumulated depreciation | 100,000 | |
| Equipment | | 100,000 |
| (eliminate accumulated depreciation) | | |
| Equipment | 60,000 | |
| Revaluation surplus (OCI) | | 60,000 |
| (uplift carrying amount HK$300,000 → FV HK$360,000; first revaluation, so increase to OCI) | | |

**解題思路（繁中）:**
- Revaluation increase = FV 360,000 − carrying amount 300,000 = 60,000；首次重估 → 全數 credit **OCI (revaluation surplus)**（HKAS 16.39），唔係 P&L。
- Option A 錯：冇 eliminate accumulated depreciation — 違反題目講明嘅 net method policy（panelist report 常批評考生 ignore stated policy）。
- Option B 錯：elimination 步驟啱，但 increase 入咗 P&L（gain on revaluation）— 只有逆轉先前同一資產嘅 P&L 減值先入 P&L，呢度係首次重估。
- Option C 錯：HK$40,000 係將 FV 360,000 同 **gross carrying amount** 400,000 比較得出嘅錯誤結果（360,000 − 400,000 = −40,000），仲當埋佢係減值入 P&L — 正確比較基準係 **carrying amount** 300,000（net of accumulated depreciation），實際係**上升** 60,000，唔係下跌。
- 考試伏位：revaluation 永遠攞 **carrying amount（net of depreciation）** 同 FV 比。

**Rule Check:** HKAS 16 para. 35(b) (elimination of accumulated depreciation); HKAS 16 para. 39 (revaluation increase to OCI)

**Common Trap（繁中）:** (1) 忘記按 stated policy 消除累計折舊；(2) 將 revaluation increase 錯入 P&L。記住「升 → OCI，除非係逆轉舊 P&L 減值」。

### Q5 — Answer: C

**Model Answer (EN):**
Revaluation decrease = carrying amount HK$4,200,000 − fair value HK$3,700,000 = **HK$500,000**.
Under HKAS 16.40, a revaluation decrease is recognised in profit or loss, **except** to the extent of any existing credit balance in the revaluation surplus **in respect of the same asset** — that portion is debited to OCI:
- Debit Revaluation surplus (OCI): HK$300,000 (exhausts the surplus for this building; balance becomes nil)
- Recognise Revaluation loss in profit or loss: HK$200,000 (the excess)

| Account | Dr HK$ | Cr HK$ |
|---|---|---|
| Revaluation surplus (OCI) | 300,000 | |
| Revaluation loss (P&L) | 200,000 | |
| Building | | 500,000 |

**解題思路（繁中）:**
- 口訣：「跌 → 先食盡同一資產嘅 surplus（行 OCI），多出嚟先入 P&L」。500,000 跌 − surplus 得 300,000 → 300,000 行 OCI、200,000 行 P&L。
- Option A 錯：全數 500,000 入 P&L，忽略咗有 300,000 surplus 可以先行 OCI 抵銷。
- Option B 錯：全數行 OCI — surplus 只有 300,000 credit，唔可以將 surplus 推落 debit balance；超出部分必須入 P&L。
- Option D 錯：OCI/P&L 調轉咗（200,000 OCI / 300,000 P&L），違反「先用盡 surplus」嘅次序。
- Surplus 係 **asset-by-asset** 計（唔可以用其他資產嘅 surplus 嚟抵）。

**Rule Check:** HKAS 16 para. 40 (revaluation decrease: OCI to extent of surplus, excess to P&L)

**Common Trap（繁中）:** 最常見錯誤係全數入 P&L 或全數扣 surplus。記住 surplus 用完即零，**永遠唔會因減值而出現 debit balance**。呢條 rule 同 impairment of revalued assets（當 revaluation decrease 處理）係考官最愛。
